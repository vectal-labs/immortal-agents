# 0047 — No CI

Status: accepted (David, 2026-09-03)

## Context

A GitHub Actions job running the test suite was proposed for the open-source
release.

## Decision

No CI. It is overthinking at this stage. The tests run locally in seconds
with `python3 -m unittest discover -s tests`, and a green badge changes nothing
about whether the watcher works.

## Consequences

- No workflow files in the repo.
- Contributors run the tests locally before opening a pull request.
- Revisit only if the project grows enough that people break tests unnoticed.
