# Synthetic fixtures

The raw captures from this experiment were removed before open-sourcing (they held session transcripts, account details, and local paths). The files here are hand-written stand-ins that keep only the failure signals the write-up and the detectors rely on. Every ID, path, and prompt is invented.

`snapshots.log` and `workdir/` are produced by `0013-capture.sh` and are gitignored.
