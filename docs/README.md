# Documentation

- [Architecture decisions](adr/) record the project's major technical and
  product choices in chronological order.
- [Experiments](experiments/) contain the outage tests, observations, and
  captured evidence behind those decisions.
- [Incidents](incidents/) document failures and the safety rules learned from
  them.
- [LaunchAgent setup](launchd.md) explains installation, logs, simulation,
  bb/Node repair, and the optional network recovery tools.

Use simulated outages for development. Real network cuts require explicit
approval and the independent safeguards documented in this repository.
